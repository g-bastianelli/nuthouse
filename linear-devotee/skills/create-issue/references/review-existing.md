# Review an existing issue

Read this only when the request concerns revision or correction of an existing Linear
issue rather than creation.

Reload the ticket, affected peer bodies, relevant decisions, and dependency closure. Apply
`../../../shared/coordination-review.md` to prepare current-state findings and exact body or
relation corrections. Give the drafter those raw sources plus the existing issue id.

Preserve source Acceptance and completed work. Return the complete correction preview
without creating a new issue or applying updates. A proposed repair does not establish
readiness until the owning workflow receives authorization, applies it, and reads the issue
back successfully.
