## Risks

- The direct-task path has no owning plugin by design. Keep the coordinator in the generated install-local workflow bundle and the execution handoff in the active turn; `warden:route` may expose the target but must remain an optional classifier rather than become a hidden orchestrator.
- Repository instructions are authoritative but unstructured. Require callers to provide extracted commands with exact repository-owned provenance and reject unknown, blank, multiline, or model-guessed commands instead of executing heuristics over arbitrary prose.
- A directory named `.moon` is insufficient evidence by itself. Require an explicit valid Moon-workspace signal plus affected graph and verifier outputs, and block rather than falling back to broad native checks when Moon scope fails.
- Strict preparation must preserve the same workflow decision identity without placing artifact contents, source code, prompts, or complete logs in the decision manifest. Store only stable artifact id/path/content-hash references and audited status in the delivery input.
- Full workflow bundle regeneration produces a large mechanical diff across six plugins. Canonical source/tests/docs are the only hand-edited bundle inputs; generated copies must be byte-identical and marketplace SHA pins remain unchanged.

## Out of scope

- Creating a Linear project, issue, milestone, dependency, or execution record; mutating Linear completion state; or reclassifying an already resolved workflow.
- Making Warden, Moon Moth, or a repository-level `_shared` directory mandatory at runtime, or adding a new package/runtime dependency.
- Implementing Acid Prophet spec/plan authoring or auditing inside the direct-task coordinator; it emits owner handoffs and validates their returned artifact metadata only.
- Parsing arbitrary natural-language repository prose into shell commands, executing verification commands inside the pure policy module, or treating command absence/failure as success.
- Commit, push, PR creation/merge, marketplace SHA updates, direct changes to the ratified specs, or unrelated project-creation/issue-delivery behavior.
