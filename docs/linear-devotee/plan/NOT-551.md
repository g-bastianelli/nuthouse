# Plan — Generate isolated cross-runtime plugin bundles (NOT-551)

## Context

NOT-551 replaces the interim Warden-only workflow mirror with one canonical, hash-addressed bundle pipeline for Acid Prophet, Linear Devotee, Moon Moth, Git Gremlin, Monkey Maestro, and Warden. The ratified parent spec is authoritative for AC-043–AC-048 and AC-051: every plugin must carry its own kernel, Claude Code and Codex must cross the same normalized boundary, optional hook/Warden/verifier paths must fall back conservatively, and release validation must run from copied install units with no repository `_shared` tree.

## Files

- `_shared/workflow/src/runtime-adapters.mjs`, `_shared/workflow/src/verification-resolution.mjs`, and `_shared/workflow/src/index.mjs` — add the canonical runtime-neutral adapter, explicit-skill fallback, normalized decision projection, and native-verification-or-block APIs exported by every bundle.
- `_shared/workflow/fixtures/*.json` and `_shared/workflow/tests/{runtime-adapters,verification-resolution}.test.mjs` — define one canonical cross-runtime/fallback corpus and test Claude, Codex, absent/failing hook, absent Warden, native verifier, and blocker outcomes against pure policy decisions.
- `scripts/workflow-bundles.mjs`, `scripts/build-workflow-bundles.mjs`, and `scripts/check-workflow-bundles.mjs` — own the explicit source inventory, deterministic SHA-256 policy hash, atomic canonical copies, stale-file cleanup, metadata generation, six-plugin inventory checks, and static rejection of `_shared` runtime imports.
- `scripts/tests/workflow-bundles.test.mjs` and `scripts/tests/workflow-install-isolation.test.mjs` — reproduce missing/stale/hash-mismatched bundles and copy each plugin install unit to a parent containing no repository `_shared` directory before importing its local bundle and running its local fixture corpus.
- `scripts/build-workflow-config.mjs`, `scripts/check-workflow-migration.mjs`, `scripts/tests/workflow-migration.test.mjs`, and `package.json` — retire the Warden-only build/check bridge without losing its unrelated migration gate; register `build:workflow` and make `check:workflow` enforce both bundle freshness and migration invariants.
- `_shared/workflow/README.md` and `{acid-prophet,linear-devotee,moon-moth,git-gremlin,monkey-maestro,warden}/lib/workflow/**` — document and generate the exact self-contained module/fixture/metadata inventory, including the native repository verification path and explicit blocker when no reliable path exists.
- Participating workflow entry skills under `{acid-prophet,linear-devotee,moon-moth,git-gremlin,monkey-maestro,warden}/skills/**/SKILL.md` — reference only the install-local bundle for workflow/profile resolution, treat hooks as optional accelerators, preserve an explicit local skill path, and never require Warden or Moon Moth.
- `{acid-prophet,linear-devotee,moon-moth,git-gremlin,monkey-maestro,warden}/{.claude-plugin/plugin.json,.codex-plugin/plugin.json}` — keep paired patch versions aligned for each shipped generated bundle.

## Risks

- The existing Warden mirror is tracked output from prior issues and `check:workflow` currently mixes mirror freshness with unrelated migration checks. Separate these concerns without weakening either gate, and preserve a compatibility command only where current scripts or docs still invoke it.
- The bundle hash must represent policy code and shipped fixture/docs bytes, not the resolved decision, timestamps, absolute paths, or target plugin. Otherwise equal policies could disagree across installs or a stale bundle could appear current.
- Directory replacement is not uniformly atomic on non-empty destinations. Stage and validate every output, atomically rename individual files in-place using unique temporary siblings, publish metadata last, and let `check:workflow` detect any interrupted or obsolete inventory.
- Hook fallback must not trust arbitrary hook output. Validate/project it through the same normalized decision contract, and invoke explicit resolution once when missing, failed, or invalid; never retry recursively or conceal policy-hash disagreement.
- A native verifier cannot be inferred from prose alone at runtime. Accept only a declared, non-empty repository-owned command set derived from instructions/build metadata; otherwise return a blocking result and preserve verification as an immutable gate.
- Skill integration spans several plugins, but this issue owns only local workflow/profile resolution and documented fallbacks. Do not implement project-creation, issue-delivery, or direct-task domain behavior from the child specs.

## Out of scope

- A shared installed workflow package, any new npm/Bun dependency, mandatory Warden or Moon Moth installation, or runtime import from repository `_shared` files.
- Domain artifact creation and delivery behavior owned by the three child workflow specs, including full project cascade, issue-plan profile semantics, relay baton, direct-task preparation, commit/PR execution, or feature acceptance.
- Changes to the ratified Acid Prophet specs, Linear dependencies or completion state, marketplace SHA pins, commits, pushes, PR creation/merge, or unrelated plugins (Saucy Status, Subroutine, Lore Hound, Stack Golem).
